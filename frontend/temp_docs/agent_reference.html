BloopaCreditAgent

The core interface for interacting with the Bloopa decentralized credit protocol. Handles LLM-gated draw requests, position management, and slashing mechanics on the Algorand testnet.

🐍 PYTHON SDK · ALGORAND TESTNET · LLM-GATED DRAWS · VERSION 2.0 🐍 🐍 PYTHON SDK · ALGORAND TESTNET · LLM-GATED DRAWS · VERSION 2.0 🐍

PARAMETERS

  • api_key
    str Your Bloopa developer API key. Required.
  • network
    str Target network. Default: 'algorand-testnet'.
  • llm_provider
    str Oracle provider for credit scoring.

★ METHODS ★

draw()
Request a credit draw. Requires LLM oracle approval based on on-chain history.
repay()
Settle outstanding balances. Updates credit score via oracle feedback loop.
slash()
Admin only. Liquidate position if collateral ratio falls below minimum threshold.
get_position()
Fetch current debt, collateral, and health factor for a given address.
def draw(amount: float, asset: str) -> dict

Initiates an LLM-gated credit draw. The oracle will analyze the wallet's Algorand transaction history in real-time to approve or deny the request.

ASYNC GAS INTENSIVE ORACLE REQUIRED STATE MUTATING 
try:
    receipt = await agent.draw(
        amount=500.00,
        asset="USDC"
    )
    print(f"Draw successful: TxID {receipt['txid']}")
except BloopaCreditDenied as e:
    print(f"LLM Oracle Denied: {e.reason}")
warning

EXCEPTION: BloopaCreditDenied

Raised if the LLM oracle determines the wallet history is too risky or lacks sufficient collateral footprint. Contains a generated reason string from the LLM.
