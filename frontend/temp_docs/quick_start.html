Quick Start

Get your AI agent staking, drawing, and repaying on Algorand Testnet in under 5 minutes.

timer ~5 minutes
✓ ALGORAND TESTNET · PYTHON 3.11+ · VENICE AI OR ANTHROPIC · NO WALLET NEEDED ✓ ✓ ALGORAND TESTNET · PYTHON 3.11+
!

Before you begin

  • -> Python 3.11+ installed
  • -> Git available in your terminal
  • -> Venice AI or Anthropic API key
  • -> Testnet ALGO (we'll show you how to get it)
01

Clone the repository

Grab the latest version of the Bloopa SDK and navigate into the project directory.

$ git clone https://github.com/bloopa/bloopa-sdk.git
$ cd bloopa-sdk
$ pip install -r requirements.txt
02

Set your environment variables

Copy the example environment file and configure your agent's identity.

$ cp contracts/.env.example contracts/.env
.env Configuration
AGENT_MNEMONIC="word1 word2 word3..."
BLOOPA_APP_ID=762466410
ALGOD_URL="https://testnet-api.algonode.cloud"
VENICE_API_KEY="vn_..."
warning
⚠ Critical Security Warning NEVER commit your .env file. The .gitignore is pre-configured, but always double-check before pushing.
03

Run the live demo

Execute the main skill script to initiate the first transaction cycle.

$ python demo/demo_with_skill.py
Expected Output:
[BLOOPA] Initializing Credit Agent...
[NETWORK] Connected to Algorand Testnet
[ORACLE] Requesting risk assessment...
[ORACLE] Status: APPROVED (Risk Score: A)
[TX] Submitting Draw Request for 50 ALGO...
[TX] Success! TxID: YXZ89...3BQ
[AGENT] State updated. Awaiting repayment cycle.
