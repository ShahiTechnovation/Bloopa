Methods Overview

Method Signature Description
opt_in() Initializes local state for a new agent.
register(uint64) Registers agent with initial stake amount.
record_payment(uint64) Logs a successful payment round.
draw(uint64) Draws funds up to current credit limit.
repay(uint64) Repays outstanding balance.
slash(address) ⚡ Anyone can slash a delinquent agent after 30 rounds.
get_position() Returns current agent metrics and tier.
enable_attestation() Opts into cross-chain attestation verification.
fund(uint64) Adds liquidity to the global protocol treasury.

⚡ SLASH IS PUBLIC

ANYONE can call slash()... No grace period. No appeals.

Tier System

TIER 0

Fresh

Default starting tier. Limited draw capacity until initial payments are verified.

TIER 1

Trusted

Unlocked after 5 successful payment rounds. Base credit limit increased.

TIER 2

Veteran

Requires consistent 30-day activity. Reduced fees and priority treasury access.

TIER 3

Elite

Maximum reputation level. Highest credit limits and DAO voting weight multiplier.
